Format de fichier non accepté : que faire ?

Un site administratif refuse votre fichier ? Dans la plupart des cas, il suffit de le convertir en PDF ou en JPG, les deux formats acceptés partout où nous avons vérifié (CAF, France Travail, MDPH).

Chargement de l'outil...

Quand un site administratif affiche « format non accepté », ce n'est presque jamais votre document qui pose problème, c'est le type de fichier. Les sites publics prennent surtout le PDF et le JPG : une photo d'iPhone en HEIC, un fichier Word, une capture en WEBP ou un dossier ZIP sont bloqués avant même d'être lus.

Les formats acceptés, d'après les pages officielles

Chaque organisme publie sa propre liste. Voici ce qu'écrivent celles que nous avons relevées :

OrganismeFormats citésTaille indiquée
CAF (Mon Compte, Caf de Paris)jpeg, pdf, jpg, png ou gifMoins de 10 Mo pour le document, pages cumulées
France Travail (pièce jointe d'un mail au conseiller)pdf, jpg, jpeg, png, gif, 3gpp, txt, html, wav, zip5 Mo maximum
MDPH en ligne (Paris)PDF, JPEG, JPG, PNG, TIF, TIFF10 Mo par fichier, 20 Mo en tout
MDPH en ligne (Haute-Garonne)PDF, JPG, PNG, TIF10 Mo par fichier, 20 Mo en tout

Le point commun saute aux yeux : le PDF et le JPG passent partout. Le HEIC, le DOCX, l'ODT et le WEBP ne figurent sur aucune de ces listes. Pour les autres organismes, la liste est en général écrite en petit sous le bouton d'ajout du fichier : lisez-la avant de préparer vos pièces.

Quel format avez-vous vraiment ?

Le nom du fichier se termine par une extension, après le point : .pdf, .jpg, .heic, .docx. Sur un téléphone, elle est souvent cachée. Quelques façons de la voir :

  • Sur iPhone : dans l'application Fichiers, appuyez longuement sur le fichier puis sur « Lire les informations ». Une photo de la Pellicule est en HEIC si le réglage « Haute efficacité » est actif.
  • Sur Android : dans l'application Fichiers ou Mes fichiers, ouvrez les détails du fichier.
  • Sur ordinateur Windows : dans l'Explorateur, menu Affichage, cochez « Extensions de noms de fichiers ».
  • Sur Mac : sélectionnez le fichier puis Fichier, Lire les informations.

Méfiez-vous des fichiers renommés à la main. Changer « photo.heic » en « photo.jpg » ne transforme pas l'image : le site peut la refuser quand même, ou l'accepter puis la rendre illisible pour l'agent. Il faut une vraie conversion.

Le format est bon mais le site refuse encore

Si le fichier est bien un PDF ou un JPG et que le refus continue, regardez ces trois pistes, dans l'ordre :

  1. Le poids. Certains sites affichent « format non valide » alors que le vrai souci est la taille. Comparez le poids du fichier à la limite du site : nos guides taille maximum CAF et taille maximum France Travail donnent les chiffres officiels.
  2. Le nom du fichier. Un nom très long, avec des accents, des apostrophes ou des emojis peut bloquer l'envoi. Renommez-le simplement, par exemple « bulletin-salaire-octobre.pdf ». Voir nom de fichier refusé.
  3. Le PDF protégé. Certains relevés bancaires téléchargés sont protégés par un mot de passe. Le site ne peut pas les ouvrir. Retéléchargez le document depuis votre espace client, ou imprimez-le en PDF depuis votre lecteur une fois ouvert.
Notre conseil : gardez une version PDF de vos justificatifs les plus demandés (pièce d'identité recto verso, justificatif de domicile, RIB, avis d'imposition) dans Mes documents. Vous les aurez prêts au bon format pour la prochaine démarche.

Pour que ça n'arrive plus avec l'iPhone

Dans Réglages, puis Appareil photo, puis Formats, choisissez « Le plus compatible ». Vos prochaines photos seront enregistrées en JPG. Pour les documents de plusieurs pages, le scanner intégré de l'application Notes ou Fichiers produit directement un PDF. Notre guide scanner un document avec son téléphone détaille la méthode.

Questions fréquentes

Pourquoi mon fichier Word est-il refusé ?

Les sites administratifs que nous avons vérifiés n'acceptent pas le DOCX ni l'ODT. Ouvrez le document dans Word ou LibreOffice, puis Fichier, Enregistrer sous ou Exporter, et choisissez PDF. Envoyez ce PDF.

Peut-on simplement renommer un fichier .heic en .jpg ?

Non. Changer l'extension ne convertit pas l'image : le fichier reste du HEIC et peut être refusé ou illisible. Utilisez un outil de conversion, comme HEIC en JPG ou HEIC en PDF.

Quel format choisir pour être accepté partout ?

Le PDF pour un document de plusieurs pages, le JPG pour une photo isolée. Ce sont les deux formats présents sur toutes les listes officielles que nous avons relevées (CAF, France Travail, MDPH).
