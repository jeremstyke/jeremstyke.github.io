🎯 Free football match prediction widget for your website (probabilities, xG)

In short

The AI Football Predictor football match prediction widget is free, with no signup and no API key. It shows a single match: win, draw and loss probabilities, expected goals, most likely score and the chance of more than 2.5 goals, updated until kickoff and then with the result. You install it by pasting two lines of code on WordPress, Wix, Blogger, Shopify or any website, and it updates itself. Today's example: Man United vs Aston Villa, Man United win 44%, draw 26%, Aston Villa win 31%.

Install in 2 minutes

  1. Pick: Configure the widget below or in the gallery, then copy the code.
  2. WordPress: Add a "Custom HTML" block and paste the code.
  3. Wix: Add an "Embed Code" (HTML iframe) element and paste the code.
  4. Blogger: Layout, add an "HTML/JavaScript" gadget, paste the code.
  5. Other sites: Paste the code where you want it in your HTML page (Shopify, Webflow, Squarespace, Joomla…).

FAQ

Is the football match prediction widget really free?

Yes, free, with no signup, no API key and no page limit. A small link to AI Football Predictor stays under the widget.

Where do the probabilities come from?

From a statistical model (Poisson and Dixon-Coles) fed with goals, expected goals (xG), form and the market. Every day we publish what we announced and what happened.

Will it slow down my website?

No: the script is tiny, loads asynchronously and the widget is lazy loaded.

Can I change the language and the colours?

Yes: data-lang for English or French, data-theme for the dark or light theme. A Pro version is coming soon.

Is this a betting site?

No. We publish probabilities, not betting advice. Probabilities, not certainties.
