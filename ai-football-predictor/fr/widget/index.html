Installer le widget en 3 étapes

  1. Choisis la compétition, un club si tu veux, le nombre de matchs et la couleur.
  2. Copie les deux lignes de code avec le bouton « Copier le code ».
  3. Colle le code dans ta page, à l'endroit où le widget doit apparaître.

WordPress : bloc « HTML personnalisé ». Wix : Ajouter › Intégrer › Code HTML. Blogger : gadget « HTML/JavaScript ». Webflow, Squarespace, Shopify : bloc « Embed » ou « Code ».

Questions fréquentes

Le widget foot est-il vraiment gratuit ?

Oui, totalement. Pas d'inscription, pas de clé d'API. La seule condition est de garder le widget tel quel, avec son lien.

D'où viennent les probabilités ?

D'AI Football Predictor, qui calcule la probabilité de victoire, de nul et de défaite de chaque match. Chaque probabilité est verrouillée avant le coup d'envoi puis comparée au vrai résultat, publiquement.

Comment ajouter le widget sur WordPress ?

Ajoute un bloc « HTML personnalisé » dans ta page ou ton article, colle les deux lignes de code, puis publie. Ça marche aussi dans un widget de barre latérale.

Le widget ralentit-il mon site ?

Non. Il est chargé en différé (lazy loading) dans un cadre séparé, après le reste de ta page.

Peut-on n'afficher qu'un seul club ou une seule compétition ?

Oui. Choisis une compétition (par exemple la Ligue 1) ou tape le nom d'un club : le code se met à jour tout seul.

Les matchs sont-ils mis à jour automatiquement ?

Oui. Le widget affiche toujours les prochains matchs, sans rien toucher.

Est-ce un conseil de pari ?

Non. Ce sont des probabilités statistiques, données à titre d'information. Réservé aux 18 ans et plus.
