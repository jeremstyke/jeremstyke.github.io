✅ Badge de fiabilité foot : montrez si les probabilités de l'IA sont justes

En bref

Le badge fiabilité probabilités foot d'AI Football Predictor est gratuit, sans inscription et sans clé d'API. Il affiche un petit badge avec notre historique public : la part des issues les plus probables qui sont arrivées comparée à ce qu'on annonçait, sur tous les matchs terminés depuis le lancement. Il s'installe en copiant deux lignes de code sur WordPress, Wix, Blogger, Shopify ou n'importe quel site, et se met à jour tout seul. Aujourd'hui : 8 issues sur 8 sont arrivées.

Installer en 2 minutes

  1. Choisissez : Configurez le widget ci-dessous ou dans la galerie, puis copiez le code.
  2. WordPress : Ajoutez un bloc « HTML personnalisé » et collez le code.
  3. Wix : Ajoutez un élément « Intégrer un code » (HTML iframe) et collez le code.
  4. Blogger : Mise en page, ajouter un gadget « HTML/JavaScript », collez le code.
  5. Autres sites : Collez le code à l'endroit voulu de votre page HTML (Shopify, Webflow, Squarespace, Joomla…).

Questions fréquentes

Le badge fiabilité probabilités foot est-il vraiment gratuit ?

Oui, gratuit, sans inscription, sans clé d'API et sans limite de pages. Un petit lien vers AI Football Predictor reste sous le widget.

D'où viennent les probabilités ?

D'un modèle statistique (Poisson et Dixon-Coles) nourri par les buts, les expected goals (xG), la forme et le marché. Nous publions chaque jour ce qu'on annonçait et ce qui est arrivé.

Est-ce que ça ralentit mon site ?

Non : le script est minuscule, se charge en asynchrone et le widget est chargé en différé (lazy).

Peut-on changer la langue et les couleurs ?

Oui : data-lang pour le français ou l'anglais, data-theme pour le thème sombre ou clair. Besoin de plus ? Nos données sont disponibles par API.

Est-ce un site de paris ?

Non. Nous publions des probabilités, pas des conseils de pari. Des probabilités, pas des certitudes.
