Installer le widget en 3 étapes

  1. Choisis la compétition, un club si tu veux, le nombre de matchs et la couleur.
  2. Copie les deux lignes de code avec le bouton « Copier le code ».
  3. Colle le code dans ta page, à l'endroit où le widget doit apparaître.

WordPress : bloc « HTML personnalisé ». Wix : Ajouter › Intégrer › Code HTML. Blogger : gadget « HTML/JavaScript ». Webflow, Squarespace, Shopify : bloc « Embed » ou « Code ».

Questions fréquentes

Le widget foot en direct est-il gratuit ?

Oui, totalement. Pas d'inscription, pas de clé d'API. La seule condition est de garder le widget tel quel, avec son lien.

Quels matchs sont affichés en direct ?

Les matchs du moment où une équipe a au moins 65 % de chances de gagner, dans 29 compétitions (Ligue 1, Premier League, Ligue des champions…). Tu peux filtrer par compétition ou par club.

Comment la probabilité évolue-t-elle pendant le match ?

Elle part de nos buts attendus d'avant-match, ajustés au temps qui reste, puis ajoutés au score actuel. Un but ou les minutes qui passent la font bouger.

À quelle fréquence le score est-il mis à jour ?

Les données sont rafraîchies toutes les quelques minutes, et la minute de jeu avance en continu dans le widget.

Comment ajouter le widget en direct sur WordPress ?

Ajoute un bloc « HTML personnalisé », colle les deux lignes de code, puis publie. Ça marche aussi dans une barre latérale.

Le widget ralentit-il mon site ?

Non. Il est chargé en différé dans un cadre séparé.

Est-ce un conseil de pari ?

Non. Ce sont des probabilités statistiques, données à titre d'information. Réservé aux 18 ans et plus.
