Raccourcir un lien Amazon : la méthode simple

Un lien de produit Amazon traîne souvent des centaines de caractères inutiles : identifiants de recherche, mots-clés, numéros de session. Pour l'envoyer par message ou le mettre dans une story, mieux vaut le raccourcir.

Étape 1 : nettoyer le lien

Tout ce qui compte dans un lien Amazon, c'est le code produit qui suit /dp/ (10 caractères, par exemple B0CXYZ1234). Le lien amazon.fr/dp/B0CXYZ1234 mène exactement au même produit que la version de 300 caractères.

Étape 2 : le raccourcir avec Hoplien

Collez le lien (nettoyé ou non) dans la case en haut de la page d'accueil et cliquez sur Raccourcir. Vous obtenez un lien du type hoplien.fr/ab3k9, facile à copier et à dicter.

Vous êtes partenaire Amazon ?

Attention : le programme Partenaires d'Amazon demande que les liens affiliés restent clairement identifiables comme des liens Amazon. Pour vos liens affiliés, utilisez le raccourcisseur officiel d'Amazon (amzn.to), disponible dans la barre SiteStripe quand vous êtes connecté à votre compte Partenaires. Hoplien convient pour les liens Amazon classiques, sans code affilié.
